# 模板使用规则

## 格式与批量

以`templates/024_存货档案_反方向数量留空.xls`为已验证的导入结构。它是含8条测试分录的样例，不是空白文件。026为已验证的两个ID、两张凭证批量样例。原始空白模板只作结构参考：其“自定义项1”尚未改成“存货档案”。

保存为Excel 97–2003 `.xls`，保持首行53列名称及顺序；不要只改扩展名。生成新文件时保留首行，替换/清空其后所有样例分录，不能在样例后直接追加真实记录。

同一凭证各分录使用同一个凭证ID，不同凭证使用不同ID。ID是本文件分组标识；026已验证ID为2、3会生成两张凭证。每个ID独立检查本币借贷平衡。凭证号可留空由平台生成。

## 列填写

以下位置为Excel列号（从1开始）：

| 列 | 内容 | 规则 |
|---|---|---|
| 1 | 凭证ID | 同一凭证一致，不同凭证不同 |
| 2–4 | 会计年、期间、制单日期 | 三者一致；按本次指定日期填写，样例日期不是默认业务规则 |
| 5、7 | 凭证类别、制单人 | 已验证“记”“王益”；切换人员需使用平台实际名称 |
| 11–12 | 科目编码、摘要 | 科目用平台编码；摘要可包含出运单和业务类型 |
| 16–17 | 币种编码、汇率 | 已验证USD/CNY；本币CNY汇率为1 |
| 18 | 单价 | 有数量核算的存货行填写 |
| 19–20 | 借方数量、贷方数量 | 只填与该行金额同方向的数量，反方向必须留空，不能填0 |
| 21–24 | 原币借方、原币贷方、借方金额、贷方金额 | 使用实际来源数值；无金额一侧沿用成功样例的0写法 |
| 27 | 客户编码 | 应收客户辅助核算对应行填写 |
| 28 | 供应商编码 | 应付供应商辅助核算对应行填写 |
| 32 | 存货档案 | 原“自定义项1”改名；填写平台存货编码，通常用于入库/结转库存行 |

编码必须作为文本保存，保留前导0、客户编码末尾“-”等字符。重量来源已确认单位为千克，但仍需核对具体存货档案的单位设置。

常见8行样例是：应收借方、外销收入贷方、销项税贷方、存货借方、进项税借方、应付贷方、销售成本借方、存货贷方。此结构只代表已验证样例，不能强制所有业务都是8行。退税、暂估、运保费等必须依据业务数据与实际科目配置处理。

## 来源及尚未定案事项

金额、供应商、重量、产品来自财务副本拆单记录。AI报关表只参考客户名。运保费为0不生成费用分录；FOB可按用户已确认的口径判定无运保费。缺必填金额或档案时列异常，不猜填、不为个别订单设例外。

“专票”曾出现在进项税分录的摘要中，其添加条件仍待财务确认，不能无条件追加。

合并边界尚未最终确定：已分别试算出运单＋报关品名、出运单＋产品类型，以及各自加报关单号的版本。按产品类型加报关单号可解释更多记录，但仍有不同产品同凭证的情况，不能宣称已确定统一合并规则，也不能把本包026样例当作最新全量生产模板。

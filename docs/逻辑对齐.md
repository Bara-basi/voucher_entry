# 与影刀程序的逻辑对齐

对齐日期：2026-10-16
基准：`前期资料/凭证自动化_影刀源码/xbot_robot/caluate.py`（已验证可行的旧版程序）
对象：本工作台的生成逻辑（`tmp/rpa_rules.py` 及其调用方）

## 一、已确认一致的部分

| 环节 | 影刀 | 本工作台 | 结论 |
|---|---|---|---|
| 分组键 | `groupby('报关单号')`，一组一张凭证 | 同 | 一致 |
| 必填字段 | 报关品名 / 供应商 / 报关金额 / 合同号_1 / 销售方式 / 币种 / 不含税人民币收入 / 不含税成本 / 采购金额，任一为空则整组跳过 | 同 | 一致 |
| 报关单号为空 | 归为一个跳过组，原因"缺失字段: 报关单号" | 本范围内 0 条（都是内销/视同销售） | 等效 |
| 收入区 | 应收(借) / 收入(贷) / 销项税(贷，为 0 不出行) / 运费(负借方，为 0 不出行) / 保费(负借方，为 0 不出行) | 同 | 一致 |
| 收入区合计 | 报关金额、销项税额、不含税人民币收入、运费、保费分别取组内合计 | 同 | 一致 |
| 采购区 | 库存商品(借) / 进项税(借) / 应付账款(贷) / 主营业务成本(借) / 库存商品(贷) | 同 | 一致 |
| 出口退税改写 | 进项税额=0 且 退税额≠0 → 科目改"应交增值税_出口退税"，金额取退税额 | 同 | 一致 |
| 产品类别 | 报关品名 → 8 位产品编号 → 前 4 位 → 产品类别 → `库存商品_{类别}` | 同 | 一致 |
| 数量 | 库存商品的借贷两行都填报关重量 | 同 | 一致 |
| 格式 | 金额四舍五入 2 位小数 | 同 | 一致 |

## 二、不一致或需要你确认的部分

| # | 环节 | 影刀 | 本工作台现状 | 处理建议 |
|---|---|---|---|---|
| 1 | 业务范围 | 只排除"预录"，内销/视同销售走内销模板（收入、内销成本、国内运费） | 只处理"销售方式=出口" | **待确认**：是否恢复内销支持 |
| 2 | 币种→科目 | 按科目名称映射，**未知币种回退到人民币**科目 | 按科目编码映射，未知币种直接报错 | 建议照抄"回退人民币" |
| 3 | 进项税行摘要 | `{合同号}采购商品`（无后缀） | `{合同号}采购商品-专票` | 建议改为无后缀（机器人凭证 237 条无后缀 / 2 条有后缀，`-专票` 是手工习惯） |
| 4 | 汇率 | 完全不处理：只填一侧金额，由平台按当日汇率折算另一侧 | 用"汇率表 + 出口日期当月"折算，两侧都填 | **待确认**：导出模板必须两侧都填，口径是否就用这个 |
| 5 | 单价 | 不填（平台按金额÷数量算） | 未输出 | **待确认**：导入模板有单价列，是否需要我们算 |
| 6 | 单位 | 数量 + 单位（"千克"→KG） | 只输出数量 | **待确认**：导入模板是否涉及单位 |
| 7 | 品名→科目 | 硬编码约 100 项品名表，精确→包含匹配，兜底"其他产品" | 照抄 | **待确认**：实际凭证出现过 140505（钛产品，如"钛管件"不在表里），是否改用用友存货档案（185 个叶子科目）做映射 |
| 8 | 回写飞书 | 写回"是否开凭证=已开 / 凭证开具日期 / 凭证开具结果=保存成功/失败原因" | 不写 | **待确认**：本工作台是否需要回写 |
| 9 | 币种覆盖 | 表里只有 USD/CNY/EUR/GBP/JPY，**没有 AUD、RUB** | 同 | **待确认**：账簿里存在澳元(112204/50010104)、卢布(112206)等科目，是否需要补齐 |

## 三、需要你拍板的问题

1. **业务范围**：本工作台是否也要生成内销凭证（影刀有完整的内销模板）？还是先只做出口？
2. **未知币种**：照影刀回退到人民币科目，还是遇到没见过的币种直接报异常？
3. **进项税行摘要**：确认去掉 `-专票` 后缀（与影刀和机器人一致）？
4. **汇率口径**：导入模板需要原币和本币两列，是否按"财务副本汇率表 + 出口日期当月"折算？若某月查不到汇率（如 2026-10 未更新），应该报异常还是回退其他口径？
5. **单价列**：是否由我们计算（不含税成本 ÷ 报关重量）？
6. **品名→存货科目**：继续用影刀的硬编码表，还是改用用友存货档案（覆盖面更全，能解决"钛管件→140505"这类缺口）？
7. **回写飞书**：是否需要把生成结果写回多维表（是否开凭证 / 凭证开具日期 / 凭证开具结果）？
8. **币种扩展**：是否补齐澳元、卢布、英镑等币种的科目映射？

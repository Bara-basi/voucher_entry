# 数据获取脚本

## 环境

在`next_step`目录下使用Python运行。`.env`沿用本次账号配置；`read_feishu.py`从此文件读取，不打印配置值。换环境参考`.env.example`。

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m playwright install chromium
```

## 飞书多维表

只读调用开放接口，自动分页取字段元数据和记录，结果写入`data/`。不包含旧财务/AI全量快照；按需重新获取。

```powershell
python scripts/read_feishu.py --output finance_source_snapshot.json
python scripts/read_feishu.py --ai --output ai_customer_reference_snapshot.json
python scripts/read_feishu.py --ai --table-name "供应商名录" --output supplier_directory_snapshot.json
python scripts/read_feishu.py --table-name "产品及类型" --output finance_product_types_snapshot.json
python scripts/read_feishu.py --metadata
python scripts/read_feishu.py --ai --metadata
```

默认主表是“2026年报关数据”；AI表的真实表名由配置表ID及接口目录校验，界面别名可能不同。表不存在或没有权限时会报错，应先看`--metadata`，不能换用另一业务表顶替。

## 用友一键只读获取

```powershell
python scripts/fetch_yonyou.py --kind mappings
python scripts/fetch_yonyou.py --kind vouchers
python scripts/fetch_yonyou.py --kind all --headed
```

通过Playwright登录并在内存会话中调用已验证读取接口。默认优先本机Chrome，否则使用Playwright Chromium；不写入登录态，不新建或保存凭证。`--headed`显示浏览器便于排查登录。输出默认写到`data/yonyou_refresh/`，不会覆盖交接快照。可使用`--output`指定目录。

映射脚本读取`mappings/platform/已验证接口及请求参数.json`，包含分页、树展平和数量核验。返回数量不符或会话失效时停止，不把半份数据标为全量。基础配置另存在configuration_reads.json；客户/供应商等以各自records文件输出。

凭证脚本读取`config/voucher_query.json`。默认查询嘉兴迈拓账簿、制单人马云凤、分录摘要包含26MT、期间2025-01至2026-12。内部ID和模板ID是原账套已验证值，换账簿/人员时需在界面重新选择并提取请求，不是只替换名称。支持`--contract`替换摘要筛选，`--period`替换期间字符串，如`2026-01,2026-09,0`。不带参数保持原抓取范围。

## 交互排查工具

`yonyou_browser.py`保留原来的JSON逐行命令入口，用于界面或接口调整排查。启动后输出页面状态；可发`login`、`snapshot`、`click`、`fill`、`press`、`events`、`request`、`task`、`close`。仅需读取时不执行保存/导入动作。

登录示例输入行：

```json
{"action":"login","user_selector":"#username","password_selector":"#password","submit_selector":"#submit_btn_login"}
```

`fetch_vouchers_task.py`可在该登录会话中运行：

```json
{"action":"task","script":"fetch_vouchers_task.py"}
```

它已改为从独立查询参数读取，不依赖原来抓包events数组。若登录有接受协议、租户选择或验证码，应在可见界面完成后再取数，不能把无权限/空返回当无业务记录。

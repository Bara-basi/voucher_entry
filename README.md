# 凭证构建工作台

从飞书多维表记录构建用友凭证导入模板，替代财务人员机械重复的录入工作。

当前范围：**合同号以 26MT 开头、销售方式 = 出口**（内销暂缓）。

## 目录结构

| 路径 | 说明 |
|---|---|
| `app/` | FastAPI 后端。`main.py` 路由，`services/voucher_service.py` 规则引擎 |
| `data/` | 运行时快照（飞书、用友导出），不入库 |
| `docs/` | 模板规则、映射方法、脚本说明、逻辑对齐、待确认事项 |
| `mappings/` | 用友档案快照、客户/供应商别名、飞书参考字典 |
| `outputs/` | 交付物：`single_voucher/`（单张凭证模板）、核对底稿 |
| `scripts/` | 飞书读取、用友只读抓取、客户匹配辅助 |
| `templates/` | 53 列导入模板（024 已验证格式） |
| `vouchers/` | 历史凭证快照（只读） |

## 快速开始

```powershell
# 1. 依赖
D:\python\python.exe -m pip install -r requirements.txt

# 2. 配置 .env（飞书 app_id/secret、表 token、用友账号）
# 3. 拉取飞书数据（当前主数据源）
D:\python\python.exe scripts\read_feishu.py --ai --table-name "2026年报关数据" --output ai_customs_source.json
D:\python\python.exe scripts\read_feishu.py --ai --table-name "汇率" --output fx_rates_ai_snapshot.json

# 4. 启动服务
D:\python\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

### 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/health` | 健康检查，返回数据快照文件是否存在 |
| GET | `/vouchers/groups` | 列出待生成的报关单号分组 |
| GET | `/vouchers/preview?customs_no=...` | 预览单个报关单号的凭证分录 |
| POST | `/vouchers/generate` | 全量生成，参数 `posting_date` / `contract_prefix` / `sale_method` / `output_dir` |

生成结果默认写入 `outputs/single_voucher/`：一个报关单号一张凭证一个 `.xls`。

## 生成口径

| 项目 | 规则 |
|---|---|
| 分组 | 按**报关单号**分组，一组一张凭证（与影刀程序一致） |
| 必填校验 | 报关品名/供应商/报关金额/合同号_1/销售方式/币种/不含税人民币收入/不含税成本/采购金额，任一为空整组跳过 |
| 收入区 | 应收(借) → 主营业务收入(贷) → 销项税额(贷，0 不出行) → 国际运费(负借方，0 不出行) → 保险费(负借方，0 不出行)；均取组内合计 |
| 采购区 | 库存商品(借) → 进项税额(借) → 应付账款(贷) → 主营业务成本(借) → 库存商品(贷)，按每条报关品名记录生成 |
| 科目 | 应收/收入按"销售方式 × 币种"；库存商品按用友存货档案编码前 4 位分类（0501 不锈钢 / 0502 镍合金 / 0505 钛 / 0506 钢 / 0508 附件 / 0599 其他…） |
| 存货档案 | 报关品名 → 用友存货档案同名叶子；同名多条优先取 05 开头编码；**档案中没有的品名直接报异常** |
| 出口退税 | 进项税额 = 0 且退税额 ≠ 0 时，进项税行改记"应交增值税_出口退税"，金额取退税额 |
| 摘要 | `{合同号}外销收入` / `{合同号}采购商品` / `{合同号}结转采购成本`；进项税、出口退税行加 `-专票`，销项税额行不加 |
| 汇率 | 海关AI「汇率」表（`tblYPyKNiJx3yOEC`），按**出口日期所在月份** |
| 金额 | 应收本币 = 报关金额 × 汇率；收入本币 = 不含税人民币收入；单价 = 不含税成本 ÷ 报关重量 |
| 客户 | 买方英文名 → 客户名称_脚本用 → 已确认别名 → 历史解析 → 档案唯一匹配；仍无法匹配则报异常 |
| 供应商 | 供应商简称 → 别名表 → 供应商档案全名唯一匹配；**字段含多个名称直接报异常，不做拆分兼容** |
| 制单 | 制单人王益，制单日期与会计期间默认取生成日期 |

## 开发约定

- 全部文件 UTF-8。
- 临时脚本放 `tmp/`（已加入 `.gitignore`），确认无用后删除。
- 服务代码放 `app/services/`，特殊脚本放 `scripts/`。
- 缺数据、缺档案一律报异常，不猜测、不自动兼容。

## 交接说明

本目录最初是 2026-10-16 整理的精简交接包：`templates/` 为已验证模板，`mappings/` 为用友档案快照，
`vouchers/` 为历史只读凭证，`scripts/` 为飞书/用友获取脚本。`.env` 含真实配置，不要上传公开仓库。

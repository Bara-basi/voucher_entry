# 凭证规则核对底稿（2026-10-16）

## 口径

- 数据源：飞书「2026年 海关AI / 2026年报关数据」（1049 条，本表取 **26MT 且销售方式=出口**）
- 业务范围：内销、视同销售不做出口报关，天然没有报关单号，不在本工作台核算范围
- 对照答案：用友嘉兴迈拓账簿 2025-12~2026-12 全部凭证（制单人 王益 为导入测试样例，已排除）
- 生成规则：影刀旧版程序 `caluate.py` 的逻辑（按报关单号分组、收入区按组合计、采购区按记录逐条、销项税为 0 不出行、进项税为 0 且有退税额时改出口退税、运保费为负借方）
- 汇率口径：财务副本「汇率」表，按**出口日期所在月份**取当月汇率
- 匹配容差：原币 ±0.02、本币 ±0.05（吸收人工舍入）

## 结果

- 分组（报关单号）：502 个
- 行级：生成 4850 行，命中 4252 行，准确率 87.7%
- 完全一致的分组：335 个
- 异常行：558 条（见 异常明细.xlsx → 缺失或金额不符）
- 待确认行：54 条（暂估业务，规则见 docs/待确认.md，不计入异常）
- 实际多出行：454 条（见 异常明细.xlsx → 实际多出）

## 说明

- 「该合同在用友侧没有业务凭证」多为尚未记账的订单，不是规则错误。
- 「疑似与同合同其他报关单合并登记」是分组边界问题：旧程序按报关单号分组，实际凭证有时按合同合并。
- 「暂估」类差异已移入上面的「待确认规则」表，规则细节见 docs/待确认.md，待财务确认后处理。
- 原先的「报关单号为空」已随范围收窄消失：全部 166 条空报关单记录都是内销/视同销售/预录，销售方式=出口且报关单号为空的有 0 条。
- 「实际多出」中的收付款、结汇、冲销凭证本就不属于本规则的生成范围，已在原因列标注。

# 单张凭证导入模板（全量）

生成日期：2026-10-19

## 内容

- `NNN_<报关单号>_<合同号>.xls`：**一张凭证一个文件**，采用 `templates/024_存货档案_反方向数量留空.xls` 的 53 列表头，凭证ID 统一为 1。
- `_生成结果.json`：成功/跳过清单，含每张凭证的记录数、行数和文件名。

## 口径

| 项目 | 规则 |
|---|---|
| 范围 | 合同号以 26MT 开头、销售方式=出口 |
| 分组 | 按报关单号分组，一个报关单号 = 一张凭证（与影刀一致） |
| 必填校验 | 报关品名/供应商/报关金额/合同号_1/销售方式/币种/不含税人民币收入/不含税成本/采购金额，任一为空整组跳过 |
| 科目 | 应收账款与主营业务收入按"销售方式×币种"；库存商品按用友存货档案编码前 4 位分类 |
| 存货档案 | 报关品名 → 用友存货档案同名叶子；同名多条优先取 05 开头编码；档案中没有则报异常 |
| 暂估 | 暂未实现，统一按正常进项税额科目处理（见 docs/待确认.md） |
| 进项税/出口退税 | 摘要带 `-专票`；进项税额=0 且退税额≠0 时改记"应交增值税_出口退税" |
| 销项税额 | 摘要不带 `-专票`；金额为 0 时不生成该行 |
| 运保费 | 组内合计为 0 不生成；非 0 时以负数记借方 |
| 汇率 | 海关AI「汇率」表，按出口日期所在月份 |
| 金额 | 应收本币 = 报关金额 × 汇率；收入本币 = 不含税人民币收入；单价 = 不含税成本 ÷ 报关重量 |
| 制单人 | 王益（导入测试用），制单日期/会计期间 = 生成日期 |
| 账簿币平衡 | 应收行本币由"不含税收入 + 销项税额 + \|运费\| + \|保费\|"倒算，应付行 = 不含税成本 + 税额（退税时取退税额），保证每张凭证借贷分毫不差 |
| 金额校验 | 若倒算的应收与"报关金额×汇率"相差超过 1 元，或成本+税额与采购金额相差超过 1 元，整组报异常（视为源数据不一致） |

## 附加订单（ADD）处理

合同号以 `-ADD` / `-ADDn` / 空格`ADD` / 直接连写 `ADD` 结尾的记录，若客户名或供应商为空，自动继承原始订单（去掉 ADD 后缀）的同名字段；
只补空值、不覆盖已有数据；原始订单有多个供应商时不推断。本次 `26MT-03T005-ADD1` 继承了 `26MT-03T005` 的客户
`Special Piping Materials Ltd`，解析为用友客户 `020640`。

注意：`&ADD` / `&ADDn` 是**联合订单**（一张报关单的货物来自多个订单，如 `25MT-01T560&ADD` 表示
`25MT-01T560` 与 `25MT-01T560-ADD` 两个订单），不属于附加订单，不参与上述继承。

补充写法说明：
- `-A` / `-B` 是**批次标记**（如 `26MT-06H056ADD1-A` = `26MT-06H056` 的 ADD1 批次 A），属合法写法；
- `Y` 是**佣金标记**（如 `26MT-07C210Y-ADD`），继承时优先找 `26MT-07C210Y`，找不到再回退 `26MT-07C210`。

## 重复客户档案

同一客户在档案中可能有多个编码（如 `000086` / `020640` 简称都是 `3-095`）。此类情况优先取凭证历史中使用次数最多的编码
（020640 使用 83 次 vs 000086 11 次），避免挂到过期档案上。

跳过的分组明细见 `_生成结果.json` 的 `skipped` 字段。
